# KonkanProducts.com — Customer MVP

Authentic Konkan specialty-food marketplace (customer shopping demo).

## Stack

- Next.js App Router + TypeScript + Tailwind CSS v4
- Client-side cart, wishlist, orders & addresses (localStorage)
- Mock checkout (UPI / card / wallet / COD UI)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Key routes

| Route | Purpose |
|-------|---------|
| `/` | Brand-first home |
| `/products` | Browse, search, filter |
| `/products/[slug]` | Product detail + reviews |
| `/cart` | Bag + coupons |
| `/checkout` | Address + payment UI |
| `/orders` · `/orders/[id]` | Confirmation & tracking |
| `/wishlist` · `/account` · `/returns` | Light account flows |
